# Context Map

This repo has multiple domain contexts. Read the relevant one before working in that area.

| Context  | Path      | Glossary            | ADRs               |
| -------- | --------- | ------------------- | ------------------ |
| Backend  | `src/`    | `src/CONTEXT.md`    | `src/docs/adr/`    |
| Frontend | `ui/src/` | `ui/src/CONTEXT.md` | `ui/src/docs/adr/` |

System-wide decisions live in `docs/adr/`. Per-context `CONTEXT.md` files are created lazily by `/domain-modeling` as terms get resolved — absence is fine.
