# Hypothesis template

Copy this into hypotheses/ for each new hypothesis.

**Claim.** If we <change>, then <funnel stage> will <move by how much>.

**Because.** The mechanism: why we think it works.

**Evidence for.** Links to evidence documents.

**Evidence against.** Links, or "none found yet".

**Confidence before testing.** Low, medium or high, and why.

**Cost to test.** People-hours and money.

**Value of knowing.** What we would do differently if it is true, and if it is false.
