# Defects we count

The loop counts these each week and drives them down. A rising count is a reason to stop and find the cause before running more experiments.

- A unit shipped with no tracking, so it cannot be measured.
- An experiment launched without a decision rule or a kill threshold.
- An experiment that ended "not tested".
- A metric used as primary that we do not trust yet.
- Evidence with no source or no date.
- A hypothesis with no mechanism ("because").
- A play written as a playbook after winning only once.

Measure before you trust a number: say for each metric whether it is trusted, noisy or not measured yet.
