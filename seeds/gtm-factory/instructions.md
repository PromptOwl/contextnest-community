# How this nest is organised

This nest runs go-to-market as a learning loop. Its product is validated learning about what reaches buyers. Reach comes from acting on it.

- **evidence/**: dated observations, each with its source and how strong it is. Quotes, numbers, competitor moves.
- **hypotheses/**: claims about what moves a funnel stage, and why. Each links the evidence for and against it.
- **experiments/**: one document per experiment, written before it starts (see experiment-rules).
- **learnings/**: what each experiment showed. A loss is as useful as a win.
- **playbooks/**: plays that won twice, written as standard work, plus the rules this loop runs on.
- **decisions/**: agreed choices, with who decided and why.
- **agents/**: saved agents. Only nest admins can approve changes here.

Every experiment is a task on the **Experiments** board. At most three are live at a time.

For agents: read experiment-rules before you draft an experiment. Never change a live experiment's decision rule.
