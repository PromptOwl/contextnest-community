# How this nest is organised

This nest is where ideas go before they become work.

- **ideas/**: one page per idea: the problem, the idea, who it is for, and its score.
- **reviews/**: notes from each weekly review.
- **decisions/**: what was promoted or dropped, and why.
- **scoring-rubric**: how every idea is scored, so scores can be compared.

Every idea is a task on the **Idea intake** board. Score it with the rubric, then the weekly review decides: promote, park or drop.

For agents: before you add an idea, search for similar ones and link them.
