A task's `ticket:` tag (its number, such as `ticket:qa-2`) no longer shows as an ordinary tag chip in the document editor, and ticket tags are no longer offered as suggestions in the tag field or the Board's bulk add-tag menu. The number still shows as the task's ID, and the server still refuses a ticket tag typed by hand on a numbered nest.
