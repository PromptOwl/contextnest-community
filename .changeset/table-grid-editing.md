Table documents can now be edited as a grid. The preview next to the CSV source is editable: click a cell to change it, use Add row and Add column to grow the table, and the × on a row or column header to remove it. Changes write straight back to the CSV, so the source and the grid always match, and `#` comment lines are kept as they were.
