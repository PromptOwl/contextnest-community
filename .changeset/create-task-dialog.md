Adding a task on the Board opens a dialog. "+ Add task" (and a card's "Add a sub-item") now opens a New task dialog with Title, Description, Assignee, Priority and Due date, instead of the inline title box. The column, swimlane, board filter tags and parent still apply; an assignee or priority column prefills the matching field, and a value picked in the dialog wins.
