Server settings: Surfaces can be turned on under Settings → Features, and its settings are editable in a new Surfaces tab — the chat buffer key, judge model, default monthly spend cap (in dollars), organization name, and the hosted Slack app (switch, client ID, client secret, signing secret). Changes apply without a restart. The buffer key and the Slack secrets are write-only (the page shows only whether they are set) and encrypted at rest. Each still falls back to its environment variable when cleared.
