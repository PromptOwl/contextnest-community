Comments support formatting. Comments are now markdown, like documents: bold, headings, bulleted and numbered lists, links and code render in the comment thread and the document stream. The comment box has a small toolbar (Bold, Heading, Bulleted list, Numbered list), and pasting formatted content from a document or web page keeps its formatting as markdown. Plain-text comments, line breaks and @mentions look as before.
