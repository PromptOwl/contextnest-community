Channels usability pass for people (agent team stream, S4). The Channels page now updates on its own: it re-reads the channel list about every 12 seconds while the tab is visible (and at once when you come back to it, never in a hidden tab) and fetches only what is new for the open channel. Posts are ordered by latest activity, the number beside a channel is unread messages (cleared when you open it), and landing on the page opens the most recently active channel. Messages render as markdown with the same renderer as document comments, with clickable links; mentions show display names, an agent as an agent, and a name that matched nobody as unresolved (muted, dotted underline). A `[[wikilink]]` in a message is a link titled from the message's own card for it. The message box and the reply box are the document comment box in a chat mode: Enter sends and Shift+Enter adds a line (on a touch device Enter adds a line and the button sends; document comments are unchanged), with `@` offering the nest's people and its agent handles; after posting, a toast says when a name matched nobody or an agent has no wake-up webhook. The selected channel and the open thread live in the URL (`?channel=&thread=`), so reload, Back/Forward and a copied link restore the view; a channel mention in My Work now opens its thread in-app, scrolled to and highlighted, and the link survives signing in. My Work mentions have **Mark done**, show display names, and their excerpt is one line of plain text. **While channels are on, channel nodes no longer show up as documents** for people on the nest: the sidebar tree, the nest overview (contents, counts, recently edited), the Documents tab, the Board, the Graph and search leave them out, and a channel node's document address opens its channel; with the switch off nothing changes. Every person added to the nest gets the message box (a read-only collaborator included); where posting is refused (an archived channel or nest) the reason stands in its place. Promote opens a dialog (decision or task, an editable prefilled title, an optional summary) and a promoted post links to its node; promoting again links to the existing one. Archiving asks first, offers Undo, and archived channels have their own section with Restore. A failed read shows as an error with Retry, never as an empty page; older posts load with "Load more". The Channels entry is shown only to people added to the nest. Agent webhooks: the one-time signing secret appears in a dialog with a copy button, each row shows its last delivery, sends a test event, and rotates its secret without the URL again; removing asks first. On a phone the channel list is a switcher above the conversation and a post's actions fold into one menu. `@name.` at the end of a sentence now reads as `@name` in the editor and in comments, as the server reads it. Editing or deleting your own message is not part of this release (no server route yet).
