The visibility button in the nest header now offers all three tiers — Private, Organization and Public — instead of flipping between Private and Public only. It is the same control as the Collaborators tab and the document top bar: each tier keeps its acknowledgement, an Organization nest moves straight to Private or Public without the detour to the Collaborators tab, a tier a server admin has restricted is shown disabled with the reason, and a failed save goes back to the value the server holds.
