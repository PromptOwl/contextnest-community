Board task rules: a nest can number its tasks (`PO-12`, click to copy), give every new task a default stage (`stage:backlog`), and keep exclusive tag groups such as `stage:` to one value per task. Stage columns follow the 8-stage workflow order with fixed colours, priorities show red to slate by urgency, and the board can group by any tag group (`#stage:`, `#surface:`). The document editor no longer shifts its prime, always-include and type rows under the cursor on focus.
