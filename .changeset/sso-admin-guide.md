Single sign-on is now fully documented. CONFIGURATION.md → Single sign-on (OIDC) is a complete admin guide: prerequisites, a settings reference (env var ↔ UI field ↔ default), step-by-step setup for Microsoft Entra ID, Google, Okta, Keycloak and any other OIDC provider, what happens to existing password accounts, invites, API keys, MCP clients and Agent SSO, offboarding, shared-deployment limits, and a troubleshooting table giving the cause and fix for every `sso_error` code. UI locations now match the Admin rail (Admin → Server settings → Single sign-on, Admin → Teammates). The in-app How it works page has a Single sign-on section for server admins.
