**View nodes are served.** A `type: view` node (§1.12) now opens as a server-rendered page at `GET /nests/:nestId/nodes/:nodeId/view/hosted` (and in the document viewer): `md`, `list`, `data`, `callout` and `html` blocks resolve for the viewer, other kinds show a placeholder. Each `html` block is a sandboxed frame (`…/view/blocks/:blockId/hosted`, no `allow-popups`, no network) whose artifact receives the blocks named in its `data_from` as a `<script type="application/json" id="nest-data">` element — only when the view and artifact versions are approved, bounded by the viewer's access (and, on ungoverned nests, every version author's), with caps and errors as data. `CN_VIEW_DATA=off` withholds all view data. Views are authored with a validated `view` field on REST create/PATCH and MCP `context_create`/`context_update`. `/p` shows a published view's intro with placeholders and never carries data. Plain artifacts, `/hosted`, `?format=raw` and `/p` for other nodes are unchanged.
