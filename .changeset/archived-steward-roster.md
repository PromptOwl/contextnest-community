An archived nest's owner is no longer told they cannot manage stewards. The steward gate read the archive-capped permission, so the owner (and the server admin) saw "You don't have permission to manage stewards" on their own archived nest. Standing is unchanged by archiving: the steward roster and the activity trace stay readable, and a change is refused as "This nest is archived".
