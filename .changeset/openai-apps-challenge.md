**Publish your server as a ChatGPT app.** OpenAI checks you own the domain by reading a token at `/.well-known/openai-apps-challenge`. Paste the token under Server settings → Features → Agent OAuth → OpenAI domain token, or set `OPENAI_APPS_CHALLENGE`. It serves right away with no restart.
