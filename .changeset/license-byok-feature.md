**Own model keys are a licence feature.** Whether the server may run on its own provider keys or LiteLLM gateway is now the `byok` licence feature — included with Enterprise, and grantable or revocable per licence by PromptOwl — instead of a field in the plan limits. With an older PromptOwl that sends no feature list, an Enterprise licence still gets it by default.
