Sharing a document takes one click. **Share public link** in a document's menu (and in the document row menu) copies its public link, or makes one first with the same defaults as the Publish dialog and says what became public, with Undo and Manage. Published pages (`/p/<slug>`) now show a title, an excerpt of the approved version and an image when the link is pasted into Slack, LinkedIn or a chat; a gated link shows no excerpt. Readers see one quiet line, **Make your own nest**, linking to this server's sign-up; a white-label nest shows none, and each link has its own switch for it in the Publish dialog (off for a document you send to a client). Published pages now ask search engines not to index them (`noindex, nofollow`, in the page and as an `X-Robots-Tag` header); link previews still work. An HTML document is now framed by the reader page so that line never goes inside it: printing such a page prints the visible part, and a script that fetched `/p/<slug>` for the HTML should fetch `/p/<slug>/view`. Agents can do the same over MCP: `context_public_link_create`, `context_public_links`, `context_public_link_update` and `context_public_link_revoke` mirror `/nests/:id/publications`; an agent must name `access_mode` when it creates a link, so an open link is never its default.
