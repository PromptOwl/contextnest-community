A Getting started screen for new people. Someone who signs in and owns no nest sees a welcome screen instead of an empty list: create their own nest in one click, connect their agents (Hootie, Claude, Duet, Muse, Grok, Hermes, Instinct, Goose) with the nest's MCP URL filled in and a check that turns green only when the agent really read the nest, then fill it — write, distill a public site or GitHub repo on the server with a default ontology kept as a versioned document in the nest, or connect their own Slack workspace. Skip closes it; Getting started on Home opens it again. New superadmin toggles: `onboarding_enabled`, `distill_enabled`, `surfaces_slack_self_serve`. New MCP tools: `context_onboarding`, `context_onboarding_update`, `context_distill`, `context_distill_status`.
