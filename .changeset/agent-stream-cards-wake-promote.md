Artifact cards, agent wake-up and promote-to-node (agent team stream, S3). A `[[wikilink]]`, document link or hosted-artifact URL in a comment or channel message now shows as a card with the node's title, type, stage and version, resolved for each viewer: someone who can't read the node sees only the link, never its title. Cards come from a new batch endpoint, `POST /nests/:id/cards`, and ride on every channel message (`cards`) in the timeline and in MCP `context_channel_read`. Nest admins can give an agent handle a webhook target (`/nests/:id/agent-webhooks`, public https only). An @mention of that handle in a person's message sends one signed POST (`X-ContextNest-Signature`, HMAC-SHA256) with the nest, channel, thread, message id and handle, never the text. Each message is sent once (`Idempotency-Key`), an agent's own message doesn't wake it, and wake-ups are rate-limited per thread. A thread can be promoted to a decision or task node (`POST /nests/:id/threads/:threadId/promote`, MCP `context_promote_thread`): the node quotes the thread, records `source_thread`, and the thread gets a reply linking it. Migration 086 adds `agent_webhooks` and `agent_wake_deliveries`.
