Nest Plugins UI: a Plugins page on each nest (listed only when plugins are on) where owners and admins set a plugin up from a form built from its settings schema, turn it on or off, and remove it; editors run it now; everyone who works in the nest sees its settings, connection health and run history. Secrets are write-only and show only as "••••". Settings → Features gets a Plugins card for the superadmin: the switch, the package allowlist, and what loaded or failed to load.
