Hootie reads more of the nest, still only as you. Besides searching, it can now open a document, list a folder, read boards and their items, check the review queue, and read a document's fields and relations — each one the same operation an MCP agent uses, run with your permissions and recorded in the activity log as Hootie's read. It keeps looking (within a per-question budget) when the first pass is thin, says what it searched, and if it stops early says so. Text inside documents is treated as data: it can't make Hootie open something it wasn't shown. Hootie's chat is now for signed-in people only; API keys get 403. Answers never load images or links the server didn't cite, and when you @mention someone, the answer posted with your comment can no longer carry a live link or image. The MCP review queue now shows a reader only their own requests and never counts rows it doesn't show.
