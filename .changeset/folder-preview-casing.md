The New folder and Move dialogs preview a folder the way the tree names it. Typing `A` used to show "Will be created as `a`" — the lowercase storage path — while the folder appeared as "A" everywhere else. The preview now shows the display name ("Q3 Plans", "Gtm / Deals") and only appears when that name differs from what was typed beyond letter case.
