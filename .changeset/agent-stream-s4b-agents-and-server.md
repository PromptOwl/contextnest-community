Channels for agents, and the server side of the channels usability pass (agent team stream, S4). **Who may post changed:** people added to the nest post in a channel, a read-only collaborator included (it was writers only). The public, someone whose only way in is a document share, and a read-only API key still can't; creating, archiving and promoting stay with the nest's writers. Channels are now members-only to read as well: a visitor to a public nest sees no channel, and the docs site leaves channel nodes out. A channel node can no longer be untagged, moved or deleted through the document routes (archive it instead). For agents over MCP: `context_my_work` lists the threads that tag the agent a key's label or `client.agent` names (`for_agent`), takes `sections` and `limit`, and no longer returns the person's notification list unless asked; `context_comment` takes `channel` (a name, `#name` or node id) or just `thread`, and returns `thread_id`, `comment_id` and what each @name reached; `context_channel_read` takes `since` and returns only what is new; a read-only key can list channels and is told plainly it can't write; the wake-up POST carries `author`, an `excerpt` and the `read` call, and a failed one is retried three times. An API key's label alone no longer shows a message as "<label>, on behalf of <person>": only a declared `client.agent` does. For the Channels page: the timeline is ordered by latest activity; every channel carries `unread` and `last_activity_at`, with `POST /channels/:name/read` to mark it read and `?since=` for a cheap refresh; `POST /me/work/mentions/:threadId/done` marks a mention done; promote takes `title` and `summary`, quotes with names and readable times, and returns the existing node instead of making a duplicate; a channel reply notifies only who it mentions; agent webhooks show their last delivery, can be tested (`POST …/agent-webhooks/:handle/test`) and rotated without retyping the URL; `GET /nests/:id/agent-handles` lists the agents a composer can offer; every message carries display names and which @names resolved. `@name.` at the end of a sentence now reaches `name`. Only a person added to the nest wakes an agent now (a visitor's comment on a public page doesn't), and the wake-up carries `author_email`. The nest activity log and the flat comment list return only what the caller can read. Migration 087 adds `stream_marks` and three columns on `agent_wake_deliveries`. No new MCP tools.
